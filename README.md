# Bao To Me Website

Static restaurant website for Bao To Me, a Pan Asian kitchen in Koramangala, Bangalore.

Live site: https://bao-to-me-website.vercel.app

## Product Read

- Problem: A restaurant needs a fast, polished web presence that makes food, location, reservations, and credibility obvious on mobile.
- User: Diners deciding whether to visit, reserve, or contact the restaurant.
- Product bet: A focused single-page site with strong visual assets, menu clarity, reviews, press, and structured local SEO can do the job without a heavy CMS.
- What shipped: A responsive static site with real food photography, menu sections, reservation paths, Google Maps, reviews, press, Open Graph metadata, and schema.org restaurant data.
- What it proves: I can ship a practical, production-ready customer-facing website with business context, content staging, SEO hygiene, and mobile polish.

## What Shipped

- Responsive one-page restaurant site.
- Menu with categorized dishes and full food photography.
- Reservation and contact CTAs.
- Google Maps/location details.
- Google and Zomato review highlights.
- Press section.
- Open Graph and Twitter Card metadata.
- Schema.org `Restaurant` structured data.
- Favicon, Apple touch icon, and social preview image.
- Vercel analytics and speed insights.

## Run Locally

This is a static HTML/CSS/JS site with no build step.

Open `index.html` directly, or run any static file server from the repository root.
